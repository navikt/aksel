Tailwind: v4 theme now uses `@theme inline`, so dark mode and `data-color` work with Tailwind utilities. Font sizes are available as `text-ax-*` and font family as `font-ax-font-family` (`font-family-ax-font-family` is deprecated). The v3 preset adds `rounded-ax-*` and no longer lists radius tokens as colors.
